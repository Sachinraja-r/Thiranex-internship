# Stock Market Analysis & ML Price Prediction
### Finance Domain - Data Science Project

## Files
- Stock_Market_Analysis.ipynb  -- Main Jupyter Notebook (submit this)
- project_report.html          -- Full project report (open in browser)
- requirements.txt             -- Python dependencies

## How to Run the Notebook
pip install -r requirements.txt
jupyter notebook Stock_Market_Analysis.ipynb

## Stocks Analysed
AAPL (Apple) . GOOGL (Alphabet) . MSFT (Microsoft) . AMZN (Amazon)
Period: January 2019 to January 2024

## What is Covered
- Exploratory Data Analysis (EDA)
- Technical Indicators: RSI, MACD, Bollinger Bands
- Feature Engineering (21 features)
- Machine Learning: Linear Regression, Ridge, Random Forest, Gradient Boosting
- Model Evaluation: MAE, RMSE, R2, MAPE
